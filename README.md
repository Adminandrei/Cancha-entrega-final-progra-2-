CanchaLista - Sistema de Reserva de Canchas
===========================================

Descripción
-----------
Aplicación de escritorio hecha en C# con Windows Forms para llevar el control de alquiler de canchas sintéticas. Permite registrar las canchas, los clientes y las reservas guardando todo en memoria mientras el programa está abierto.

Objetivo
--------
Evitar que se crucen dos reservas a la misma hora y facilitar el cálculo de cobros y la consulta de horarios libres.

Integrante
----------
- Andrei Sibaja Boalños (GitHub: @Adminandrei)

Tecnologías utilizadas
----------------------
- C# con Windows Forms (.NET)
- Visual Studio
- Git y GitHub

Funcionalidades iniciales (Avance 1)
------------------------------------
- Menú principal para moverse entre pantallas y botón para salir del programa.
- Registro de canchas en memoria (código, nombre y precio por hora) con validaciones y limpieza de campos.
- Tabla (DataGridView) para ver las canchas guardadas.

Estado del proyecto
-------------------
En desarrollo - Avance 1.

Estructura del proyecto
-----------------------
- src/: Código fuente organizado en Presentacion, Logica y Datos.
- docs/: Propuesta y manuales del sistema.
- evidencias/: Capturas de pantalla de cada avance.

Ejecución
---------
1. Descargar o clonar el repositorio.
2. Abrir el archivo .sln que está dentro de la carpeta src con Visual Studio.
3. Darle a Iniciar (o presionar F5) para correr el programa.
